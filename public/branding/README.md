# Logotipo oficial

O logotipo foi exibido na conversa, mas o arquivo PNG não foi disponibilizado no executor. Não foi redesenhado com CSS nem substituído por outro símbolo.

Adicionar `mdfreitas-logo.png` nesta pasta. O componente `Brand` detecta automaticamente `/branding/mdfreitas-logo.png` se o arquivo existir. `NEXT_PUBLIC_LOGO_PATH` é opcional para outro nome local permitido. Depois de adicionar o arquivo, reconstruir o site.

O componente usa `next/image`, alt descritivo, dimensões reservadas e object-fit contain. Até lá, mostra apenas o nome da empresa em texto. Conferir nitidez, proporções, áreas vazias e contraste da imagem no cabeçalho e rodapé em 390, 768 e 1440 px. Essas verificações da imagem oficial ainda estão pendentes.
